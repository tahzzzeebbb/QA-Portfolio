# AI Prompt Library

This file contains useful AI prompts for QA Engineers.

---

## Prompt 1 - Test Case Generator

You are a Senior QA Engineer.

Generate professional manual test cases for:

https://the-internet.herokuapp.com/login

Include:

- Test Case ID
- Test Scenario
- Test Case
- Preconditions
- Test Steps
- Test Data
- Expected Result
- Priority

Generate:

- Positive Test Cases
- Negative Test Cases
- Boundary Test Cases
- Validation Test Cases
- Usability Test Cases

Return the result in table format.
